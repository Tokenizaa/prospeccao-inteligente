# Exemplo de segmento: serviços jurídicos

Exemplo ilustrativo de configuração, não uma lista de leads nem uma autorização para coletar ou contatar pessoas.

## Objetivo possível

Identificar organizações que publicam sinais comerciais relevantes para um serviço jurídico específico, usando fontes públicas ou autorizadas e critérios definidos pelo responsável.

## Cuidados específicos

- Não inferir que uma pessoa precisa de serviço jurídico com base em dados sensíveis.
- Não coletar detalhes de processos ou dados pessoais sem finalidade e autorização adequadas.
- Não apresentar uma hipótese comercial como necessidade jurídica comprovada.
- Revisar publicidade profissional e regras aplicáveis à atividade antes de automatizar contatos.
- Exigir revisão humana de mensagens e critérios de qualificação.
