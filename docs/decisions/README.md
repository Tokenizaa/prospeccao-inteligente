# Decisões arquiteturais

Registre aqui decisões que alterem contratos, arquitetura, segurança, modelo de dados, dependências ou compatibilidade.

## Modelo recomendado

Crie um arquivo `NNNN-titulo.md` com:

- **Status:** proposta, aceita, substituída ou rejeitada
- **Contexto:** problema e restrições observadas
- **Decisão:** escolha feita e motivo
- **Alternativas:** opções consideradas
- **Consequências:** benefícios, custos, riscos e migração
- **Validação:** como verificar se a decisão funciona

Não registrar suposições como fatos nem criar uma decisão retroativa para justificar uma mudança não documentada.
